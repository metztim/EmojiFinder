# EmojiFinder

Emoji and Unicode character search for macOS on Apple Silicon. Press a shortcut, type a word, copy the glyph.

EmojiFinder is a fork of [Glyphfinder](https://github.com/ueberdosis/glyphfinder) by überdosis, which was discontinued in 2022 and only shipped as an Intel build, so it no longer starts on Apple Silicon Macs without Rosetta. This fork rebuilds the app on a current Electron so it runs natively on M-series Macs, refreshes the emoji list, and ranks search results.

Ready-to-run download: [latest release](https://github.com/metztim/EmojiFinder/releases/latest). Source: this repository.

## Features

- 35,071 characters and emoji, searchable by name, tag, look-alike, HTML entity, or the character itself
- Emoji through Unicode 17, with the keywords of the Unicode CLDR annotations and common shortcodes
- Results ranked so that exact names, emoji, and often-used glyphs come first
- Menu bar app with a global shortcut (Control + Command + G by default), or a standalone window
- Frequently used glyphs pinned to the top
- Keyboard shortcut for the current keyboard layout, HTML entities, and code points per glyph
- Light and dark mode, following the system or set by hand
- Works offline; no account, no license key

## Download

Requires an Apple Silicon Mac running macOS 13 or later.

1. Download `EmojiFinder-<version>-arm64.dmg` from the [latest release](https://github.com/metztim/EmojiFinder/releases/latest).
2. Open the DMG and drag EmojiFinder to Applications.
3. Open EmojiFinder. macOS will say it cannot verify the app, because the build is not notarized with Apple. Open System Settings, go to Privacy & Security, scroll down, click "Open Anyway", and confirm. This is needed once.

EmojiFinder then lives in the menu bar. Press Control + Command + G to open it, type, and press Enter to copy.

If you had Glyphfinder installed, EmojiFinder imports its preferences, shortcut, and usage history on first launch. The old app and its data are left untouched.

## Development

Requirements: Node 22, Xcode command line tools (for the native keymap module).

```sh
npm install        # also compiles native-keymap for the bundled Electron
npm run dev        # hot-reloading development build
npm run build      # compiles main, preload, and renderer into out/
npm run dist       # builds and packages EmojiFinder.app and a .dmg into release/
npm run data       # regenerates the glyph dataset from data/upstream-glyphs.json and emojibase-data
```

Development runs use the real settings directory. To keep them apart, point `EMOJIFINDER_USER_DATA` at any other directory.

### Headless smoke test

`EMOJIFINDER_DEBUG_ACTIONS` takes a JSON list of steps (type a query, press keys, take a screenshot, quit) and runs them against the built app without a person at the keyboard. The step format is documented in `src/main/services/debug.js`.

```sh
EMOJIFINDER_USER_DATA=/tmp/ef EMOJIFINDER_DEBUG_ACTIONS='[{"type":"query","value":"star"},{"type":"shot","path":"/tmp/star.png"},{"type":"quit"}]' npx electron .
```

## Architecture

| Layer | Location | Job |
|---|---|---|
| Main process | `src/main/` | Window and tray, settings store, global shortcut, theme, keyboard layout lookup, glyph cache file |
| Preload | `src/preload/index.js` | The only bridge between renderer and main (`window.emojifinder`) |
| Renderer | `src/renderer/src/` | Vue 3 UI: search field, virtualized glyph grid, glyph card, preferences |
| Search worker | `src/renderer/src/workers/search.worker.js` | Holds the dataset, checks which glyphs the installed fonts can draw, builds the FlexSearch index, ranks results |
| Dataset | `src/renderer/src/data/glyphs.json` | Generated by `scripts/build-data.mjs` |

The font-support check renders every glyph once and compares it with the fallback "tofu" box. Its result is cached in the settings directory, keyed by dataset version, app version, and macOS version, so it reruns only when one of those changes or when "Rebuild Emoji Cache" is used in Preferences.

## Data

`data/upstream-glyphs.json` is the Glyphfinder 1.4.1 dataset with the tags, sets, and look-alikes überdosis curated in their spreadsheet. `scripts/build-data.mjs` adds every emoji from `emojibase-data` that the upstream set lacks and widens the tags of existing emoji with the current CLDR keywords and shortcodes. Bump `emojibase-data` and run `npm run data` when a new Unicode version ships.
